# SA'YA Umroh OS

Operating system for SA'YA Umroh travel management (Retali).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The **Owner Dashboard** lives at [`/dashboard/owner`](http://localhost:3000/dashboard/owner).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Recharts (analytics)
- Framer Motion (motion)
